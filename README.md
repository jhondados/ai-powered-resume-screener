# 👔 AI-Powered Resume Screener

[![Applications](https://img.shields.io/badge/Daily%20Volume-10K%20resumes-blue)](.) [![Accuracy](https://img.shields.io/badge/Quality%20Match-94%25-green)](.) [![Bias](https://img.shields.io/badge/Bias%20Monitoring-Active-orange)](.)

> **AI recruitment platform** processing 10K resumes/day. LLM extracts skills, experiences and achievements, scores job fit (94% accuracy) and detects potential bias. Generates personalized interview questions per candidate.

## ✨ Features
- **Structured extraction**: skills, education, experience, achievements from any resume format
- **Skills graph**: maps candidate skills to job requirements with gap analysis
- **Fit scoring**: multi-dimensional match score (technical/cultural/growth)
- **Bias detection**: flags gender, age, name-based patterns in screening decisions
- **Interview gen**: 10 tailored questions per candidate based on resume + JD
